Comprendre et essayer

Un même problème peut demander une méthode, une source à consulter ou un logiciel à interroger. Repère ce dont tu as besoin.

Skill · comment faire

Un skill enregistre une méthode que tu peux réutiliser. Dans SKILL.md, le nom et la description aident l’assistant à le repérer. Lorsqu’il est sélectionné ou jugé pertinent, l’assistant peut charger les instructions et les ressources associées.

Exemple BTP · Comparer deux devis en citant les lignes sources, en recalculant les totaux et en signalant les quantités à confirmer.

Connecteur · où chercher ou agir

Associe d’abord le service avec ton compte, puis choisis-le dans le chat. Le connecteur peut lire ou agir selon les droits accordés et les fonctions qu’il expose. Après une recherche, ouvre la source renvoyée pour la contrôler.

Exemple BTP · Retrouver le plan P02 dans Drive et vérifier son indice dans le cartouche. Un serveur MCP peut aussi donner accès à un outil spécialisé, par exemple lire la vue active dans Revit.

Que taper pour appeler un skill ou un connecteur ?

Quand un menu s’ouvre, sélectionne l’élément proposé, puis ajoute ta demande. Le raccourci dépend de l’assistant et des accès disponibles.

Gemini
Skill · / ou @ selon le déploiement, puis choisis la compétence. Connecteur · @, puis sélectionne Drive si l’application est activée.
ChatGPT
Skill · @, puis sélectionne la méthode si elle apparaît. Connecteur · @ ou + et choisis l’app associée dans ton compte.
Claude (chat)
Skill · active-le dans Personnaliser → Skills, puis demande de l’utiliser par son nom. Connecteur · ouvre + ou / → Connecteurs.
Codex CLI et Claude Code
Skill · $nom-du-skill ou /skills dans Codex CLI, /nom-du-skill dans Claude Code. MCP · une fois le serveur configuré, nomme l’outil à utiliser dans ta demande.

Menu absent ? Colle les instructions du skill dans le chat. Pour tester un connecteur sans le connecter, joins les deux pièces fictives à comparer.

Trouver un skill ou un connecteur

Écris le résultat que tu veux d’abord. Par exemple « comparer deux révisions de devis » ou « lire les plans d’un dossier Drive ».

Chercher un skill

  1. Commence dans ton assistant ou sur le Web avec agent skill construction daily report SKILL.md.
  2. Sur GitHub, ouvre le fichier SKILL.md dans le dépôt d’origine. Lis le déclencheur, les étapes, les fichiers requis et les scripts éventuels.
  3. Vérifie la licence, l’activité et la compatibilité. Pour un premier test, choisis une méthode à lire et essaie-la sur une donnée fictive.
  • Constructelligence · méthodes de chantier — coordination, préparation de chantier et questions techniques.
  • OpenAI · catalogue Codex — exemples de méthodes pour fabriquer et tester des outils.
  • Anthropic · exemples de skills — fichiers de travail et structure des méthodes. Consulte la licence du dossier choisi.

Chercher un connecteur

  1. Dans Gemini utilise Paramètres → Applis connectées. Dans ChatGPT ouvre le répertoire d’apps. Dans Claude, utilise Personnaliser → Connecteurs.
  2. Vérifie le compte, les droits de lecture ou d’écriture et l’action exacte. Cherche dans la documentation du service si le répertoire laisse un doute.
  3. Pour un logiciel métier, cherche aussi sur le Web ou GitHub le nom du logiciel, sa version et MCP. Regarde qui publie le projet, les versions supportées, la licence et les actions réellement disponibles.
  4. Teste une lecture simple avec une pièce connue, puis compare le résultat au document ou au logiciel.
